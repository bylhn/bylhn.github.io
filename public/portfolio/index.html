Research Paper · Cybersecurity Law · 백석대학교 컴퓨터공학부

화이트해커의 법적 지위 확립을 위한 인증 및 윤리 관리 제도 연구

화이트해커의 법적 공백 문제를 분석하고, 인증·평가·서약·교육 4단계 제도를 제안한 학술 연구. (공동저자: 김한별, 이근호)

▶ 논문 보기
Problem
화이트해커는 법적 지위가 모호해 선의의 보안 점검조차 처벌 위험에 노출되어 있다. 이 법적 공백은 보안 연구를 위축시키고 국가 보안 체계에 부정적 영향을 미친다.
Proposal
① 화이트해커 인증제 — 자격·평가 과정을 거쳐 공인된 해커로 활동. ② 윤리·심리 평가 시스템 — MMPI·SJT·CTF/PoC 다단계 평가. ③ 비밀 서약 기반 제한적 공개 — 국가기관 승인을 거친 취약점 공개. ④ 정기 법률·윤리 교육 프로그램 — 연 1회 최신 법률 동향 및 사례 교육.
Conclusion
화이트해커가 불법의 경계에 머무르지 않고 국가 보안의 핵심 자산으로 자리매김하는 전환점을 제시한다. 기술 역량뿐 아니라 공익 의식과 사회적 책임을 갖춘 보안 인재 성장의 제도적 기반을 마련한다.

실습 시나리오 01 · File System Forensics

파일 삭제 흔적 분석

가상의 내부 조사 시나리오를 설정하고, NTFS 아티팩트를 활용해 삭제된 파일의 흔적과 사용자 행동을 복원하는 과정을 직접 수행했다.

▶ 풀이 보기
Situation
특정 시점 이후 사용자가 주요 문서를 삭제했다는 의혹이 제기된 시나리오. 공식 저장소에는 해당 파일이 존재하지 않는 상태에서 분석 시작.
Evidence
$MFT 잔존 엔트리, $LogFile 트랜잭션 로그, 쉘 링크(.lnk) 파일, 레지스트리 RecentDocs 키.
Analysis
MFT 분석으로 삭제 파일의 이름·크기·타임스탬프 복원. $LogFile에서 삭제 연산 순서 역추적. LNK 파일 접근 시각과 교차 검증.
Reconstruction
의혹 시점 4분 전 명시적 삭제. 삭제 직전 12초간 해당 파일이 열려 있었음을 타임라인으로 확인.
Conclusion
삭제 행위는 우발적이 아닌 의도적 조작으로 판단. 복원된 타임라인은 이후 조사의 핵심 근거로 활용될 수 있음을 확인.

실습 시나리오 02 · Log Analysis

사용자 행동 로그 분석

세션 하이재킹 침해 시나리오를 설정하고, 시스템 로그로부터 행동 흐름을 역추적해 전체 경위를 재구성하는 분석을 수행했다.

▶ 풀이 보기
Situation
특정 계정에서 비정상적인 접근 패턴이 감지된 시나리오. 피해 발생 경위가 불명확한 상태에서 분석 시작.
Evidence
웹 서버 액세스 로그(Apache), 세션 토큰 발급 기록, 사용자 에이전트 문자열, IP 지오로케이션 데이터.
Analysis
로그 정규화 후 시계열 정렬. 동일 세션 내 물리적으로 불가능한 이중 접속 위치 확인. 자동화 요청 패턴(간격 균일성) 탐지.
Reconstruction
세션 하이재킹 이후 봇 기반 자동화 스크립트가 17분간 작동. 행동 흐름을 6단계 타임라인으로 재구성.
Conclusion
외부 침입자에 의한 세션 탈취로 결론. 복원된 행동 로그는 계정 피해 범위 산정의 기준이 될 수 있음을 확인.

Assignment · 2026.04

윈도우 파일 행위에 따른 MAC Time 변화 분석

파일 생성·복사·수정·액세스 각 행위가 NTFS 타임스탬프에 미치는 영향을 실측하고, 레지스트리 및 시스템 시간 조작 시나리오까지 검증한 실습 보고서.

▶ 보고서 보기
Scope
LG 그램 노트북 (Windows 10.0.26100.1) + SanDisk USB. 파일 버전 단위 타임스탬프 변화, 레지스트리 NTFSDisableLastAccessUpdate 조작, exFAT 포맷 USB 삽입 비교.
Key Findings
① 복사 시 Created·Accessed 갱신, Modified는 원본 유지. ② 레지스트리 값 0 설정 후 약 1시간 대기 시 Accessed가 실제 읽기 시각으로 갱신됨. ③ exFAT USB에서는 읽기 수행 시 Accessed 비갱신. ④ 시스템 시간 과거 조작 시 Modified·Accessed가 과거 시각으로 덮어씌워짐.
Conclusion
파일 유형과 시스템 환경에 따라 MAC Time 변화 패턴이 상이하며, 시스템 시간 조작은 타임스탬프 증거의 신뢰도에 직접 영향을 준다. 포렌식 분석 시 파일 시스템 종류와 레지스트리 설정을 반드시 선행 확인해야 한다.

CTF · HUB 정보보안 동아리

이미지 메타데이터 내 은닉 플래그 추출

육안으로 이상이 없는 JPEG 파일에서 ExifTool을 활용해 숨겨진 데이터를 식별한 CTF 문제 풀이.

▶ 풀이 보기
Target
ugly_cat.jpg — 외관상 이상 없는 일반 JPEG 파일.
Analysis
ExifTool로 메타데이터 접근 → 생성 시각과 수정 시각이 7초 이상 차이남을 확인. 코멘트(주석) 필드에 문자열 데이터 존재 확인.
Conclusion
메타데이터 코멘트 필드에 플래그 HUB{Ug1y_C4t_Ewww} 은닉 확인. 육안 검사만으로는 탐지 불가능하며, 메타데이터 분석이 초기 트리아지 단계에서 필수임을 확인.

CTF · HUB 정보보안 동아리

PPTX 내부 비가시 이미지 리소스 식별

PPTX 파일에 숨겨진 이미지를 파일 포맷 구조 분석으로 추출하고, 손상된 PNG 헤더를 확인한 CTF 풀이.

▶ 풀이 보기
Target
report.pptx — 슬라이드상 이미지가 보이지 않으나 내부에 이미지 리소스가 존재하는 파일.
Analysis
PPTX를 ZIP으로 해제 → Media 폴더 내 이미지 파일 확인. WSL 환경에서 헥사 덤프 분석 → PNG 정상 시그니처(89 50 4E 47)가 존재하지 않음. 파일 헤더 손상 확인.
Conclusion
파일 확장자와 외형에 의존하는 분석의 한계를 실증. 헤더 시그니처 검증이 파일 무결성 확인의 핵심임을 확인. 헤더 손상 원인 규명을 위한 추가 검증 필요성 제시.
