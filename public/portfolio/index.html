About

흔적을 읽는 사람

글쓰기에서 시작했다. 언어로 사실을 기록하고, 기록으로 맥락을 복원하는 일이 좋았다. 그 관심은 자연스럽게 디지털 포렌식으로 이어졌다—삭제된 파일, 남겨진 로그, 보이지 않는 행동의 흔적.

분석 사례

Case 01 · File System Forensics

파일 삭제 흔적 분석

삭제된 파일의 잔존 흔적으로부터 사용자 행동을 복원한다.

▶ 사례 열기
Situation
특정 시점 이후 사용자가 주요 문서를 삭제했다는 의혹이 제기되었다. 공식 저장소에는 해당 파일이 존재하지 않았다.
Evidence
$MFT 잔존 엔트리, $LogFile 트랜잭션 로그, 쉘 링크(.lnk) 파일, 레지스트리 RecentDocs 키.
Analysis
MFT 분석으로 삭제 파일의 이름·크기·타임스탬프 복원. $LogFile에서 삭제 연산 순서 역추적. LNK 파일 접근 시각과 교차 검증.
Reconstruction
의혹 시점 4분 전 명시적 삭제. 삭제 직전 12초간 해당 파일이 열려 있었음을 타임라인으로 확인.
Conclusion
삭제 행위는 우발적이 아닌 의도적 조작으로 판단. 복원된 타임라인은 이후 조사의 핵심 근거로 활용되었다.

Case 02 · Log Analysis

사용자 행동 로그 분석

시스템 로그에서 행동 흐름을 역추적하여 전체 경위를 복원한다.

▶ 사례 열기
Situation
플랫폼 내 특정 계정에서 비정상적인 접근 패턴이 감지되었다. 피해 발생 경위가 불명확한 상태였다.
Evidence
웹 서버 액세스 로그(Apache), 세션 토큰 발급 기록, 사용자 에이전트 문자열, IP 지오로케이션 데이터.
Analysis
로그 정규화 후 시계열 정렬. 동일 세션 내 물리적으로 불가능한 이중 접속 위치 확인. 자동화 요청 패턴(간격 균일성) 탐지.
Reconstruction
세션 하이재킹 이후 봇 기반 자동화 스크립트가 17분간 작동. 행동 흐름을 6단계 타임라인으로 재구성.
Conclusion
외부 침입자에 의한 세션 탈취로 결론. 복원된 행동 로그는 계정 피해 범위 산정의 기준이 되었다.
