윈도우 응용 프로그램 사용 흔적 조사

Assignment · 2026.05 · Application Artifacts

HWP·HCell·Chrome·KakaoTalk 4개 앱의 실행 및 사용 흔적을 Prefetch, 레지스트리 MRU, Jump List, SQLite DB 등 다중 아티팩트로 교차 분석한 실습 보고서.

실습 범위

HWP (Run Counter 408), HCell (Run Counter 22), Chrome (Run Counter 1,204 · 다운로드 310건 · 쿠키 4,852개 · 로그인 사이트 23개), KakaoTalk (Run Counter 1,205 · EDB 채팅 파일). 분석 도구: WinPrefetchView v1.37, JumpListsView v1.16, RegEdit, UserAssistView v1.02, DB Browser for SQLite v3.13.1.

관찰한 결과

① Prefetch Run Counter로 각 앱의 실행 빈도·마지막 실행 시각 확인.

② 레지스트리 MRU + Jump List 교차 분석으로 최근 열람 문서 목록 복원.

③ Chrome SQLite DB(History·Login Data·Cookies)에서 방문 기록·계정 정보·쿠키 4,852개 추출.

④ KakaoTalk EDB 채팅 파일 복호화는 키 미확보로 실패 — 한계로 명시.

기록의 결론

단일 아티팩트 의존 분석의 한계를 실증하고, Prefetch·레지스트리·DB 다중 소스 교차 검증이 행동 재구성의 신뢰도를 높임을 확인. 복호화 실패 사례를 통해 암호화된 아티팩트에 대한 키 관리 및 법적 접근 방법의 중요성을 인식.
